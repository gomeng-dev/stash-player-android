# Code of Conduct

## Our pledge

We want Stash Android Player to be a respectful, practical, and privacy-conscious project. Everyone participating in this project is expected to help keep the community welcoming and constructive.

## Expected behavior

- Be respectful of other contributors and users.
- Assume good intent, but accept corrections gracefully.
- Keep discussions focused on the project, Android development, Stash integration, and user experience.
- Share only safe, non-private examples, screenshots, logs, and fixtures.
- Respect that this project is used with self-hosted personal media libraries; privacy matters.

## Unacceptable behavior

- Harassment, insults, threats, stalking, or sustained disruption.
- Sexualized, violent, or otherwise inappropriate comments directed at people.
- Posting private media, credentials, server URLs, logs, filenames, or identifying information without permission.
- Doxxing or encouraging others to reveal private information.
- Spam, trolling, or repeated off-topic arguments.

## Reporting

If you see behavior that violates this code of conduct, please report it through the project's GitHub issue/contact channels. Do not include private media, credentials, API keys, cookies, or sensitive server details in public reports.

Maintainers may remove comments, close issues, block users, or take other action needed to protect the project and its community.

## Attribution

This code of conduct is inspired by the Contributor Covenant and adapted for this project's privacy-focused context.
